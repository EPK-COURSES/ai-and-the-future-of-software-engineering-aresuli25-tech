# Personal Reflection

After researching AI coding and development tools, I realized how much software engineering is changing. I was surprised by how quickly AI tools can generate code, documentation, and project suggestions.

One concern I have is that developers may become too dependent on AI and stop improving their own programming skills. AI-generated code is not always correct and can sometimes contain bugs or security problems.

At the same time, I see many opportunities. AI can help developers save time, increase productivity, and focus on more complex problems. It can also help students learn programming concepts faster.

I believe that important skills such as problem-solving, critical thinking, communication, and system design will remain valuable even as AI becomes more advanced.

In the future, software engineers should learn how to work effectively with AI tools while continuing to develop strong technical fundamentals. Personally, I plan to use AI as a learning and productivity tool, but I will always verify and understand the code before using it.

Overall, my opinion is that AI will assist software engineers rather than replace them. Developers who adapt to these changes will have better opportunities in the future.
